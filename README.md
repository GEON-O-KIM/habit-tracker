# 습관 트래커

오늘의 습관을 체크하는 간단한 PWA. HTML/CSS/JS만 사용하며 데이터는 브라우저 `localStorage`에 저장됩니다.

## 기능
- 습관 추가 (이름 + 목표 일수)
- D-day 동시 표시: 경과일 `D+N` / 목표까지 `D-N`
- 어김 버튼 → D-day 즉시 초기화 + 어긴 횟수 누적
- 참음 버튼 → 참은 횟수 기록 (D-day 유지)
- 오늘 완료 체크, 진행률 바
- 홈 화면 설치(PWA), 오프라인 동작

## 로컬 실행
```
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000`

## 아이폰 설치
Safari로 배포된 주소 접속 → 공유 → "홈 화면에 추가"
